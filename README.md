# Çamaşır Makinesinin Son Tur Konseri

Bu depo, ev tipi çamaşır makinesinin **son sıkma turunu** resmi bir stadyum konseri olarak belgeleyen ulusal protokoldür.

Bilimsel dayanak yoktur. Duygusal dayanak aşırıdır. Tambur döner, evren alkışlar, çoraplar set listesini ezberler.

## Neden var?

Çünkü 1200 devirde dönen bir silindir, eğer ciddi bakarsan, bir sahne ışığıdır.  
Çünkü tek kalan çorap solo yapmak ister.  
Çünkü kapak kilidi açılmadan önceki o iki dakika, aslında encore'dur.

## Kuruluş

```bash
python3 konser.py --dakika 3 --encore
```

Çıktı: resmi sahne akışı, koro tezahüratı, tambur ASCII'si. Gerçekten çalışır. Gerçekten ıslak hissettirir.

## Teknik özellikler (ciddi kısım)

- Dil: Python 3
- Bağımlılık: standart kütüphane (makine zaten yeterince gürültülü)
- Lisans ruhu: çamaşırını başkasının tamburuna atma
- Güvenlik: kapağı program bitmeden açmaya çalışmayın; yazılım da, makine de kızabilir

## Sahne kuralları

1. Yumumuşturucu bir enstrümandır, sos değil.
2. Koyu renkler ve açık renkler aynı sette çalınmaz.
3. Tek çorap, solo sanatçıdır; eşini aramayız, saygı duyarız.
4. 1400 rpm üstü festival sürümüdür. Komşuya haber verin.
